# 三国主要人物扩展范围

更新时间：2026-07-30

## 1. 本轮目标

本轮把正式历史人物从 24 人扩展到 200 人，覆盖魏、蜀、吴及汉末群雄／其他
主要人物。新增 176 人只补充人物身份、常用字／别名、历史归属、展示阵营和可定位
传记来源。

正式关系仍为原有 33 条，不增加战争、敌对、主从、官职、联盟、事件或阵营连线，
也不为没有亲属记录的人物补造关系。没有现有类型关系的人物允许作为独立节点存在。

## 2. 纳入与排除标准

纳入标准：

- 在《三国志》本纪、列传或明确附传中有可定位记录；
- 对三国政权、主要军政集团或汉末割据格局具有较高叙事重要性；
- 司马懿、司马师、司马昭以《晋书》帝纪补充定位；
- 汉献帝、何进、张角、王允以《后汉书》本纪或列传补充定位。

本轮不纳入：

- 仅见于《三国演义》或后世传说、缺乏历史层身份依据的人物；
- 只依赖 Wikidata 等结构化数据才能确认的人物；
- 无法可靠区分同名身份的人物；
- 为连接地图而推导出的中间亲属、政治关系或事件关系。

新增人物的生卒年若未在本轮逐项核定，一律保留为未知，不采用结构化候选日期。

## 3. 展示阵营

展示阵营是地图颜色与分区，不等同于人物一生中的正式政治归属。
`Person.visualFaction` 与 `Person.factions` 分开保存。

## 4. 史料与许可处理

- 《三国志》使用卷三至卷六十四中与本轮名单对应的本纪、列传定位；
- 《后汉书》使用卷九、卷六十六、卷六十九和卷七十一；
- 《晋书》使用卷一、卷二；
- 来源记录只保存作品、卷次、篇名和原文页面链接；本批没有复制新的现代标点
  长文本，也没有为新增来源编造短引文；
- 维基文库页面只作为公开原文阅读入口，正式历史依据仍标识为古籍本身；
- Wikidata 候选层继续默认隐藏，不能单独把人物提升为正式核验状态。

## 5. 实现边界

正式人物位于：

```text
src/data/persons.json
src/data/majorPersons.ts
```

本轮新增来源位于：

```text
src/data/majorSources.ts
```

正式关系仍只来自：

```text
src/data/relations.json
```

任何后续批次若要新增关系，都必须继续限定在当前六种关系类型，并单独完成直接史料
审核；本轮人物扩展本身不构成新增关系的授权。
