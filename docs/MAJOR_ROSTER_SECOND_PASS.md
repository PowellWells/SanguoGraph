# 第二批主要人物二次复核：既有节点姻亲与宗族关系

更新时间：2026-08-11

## 范围与原则

本轮对关系覆盖队列中剩余的 71 名第二批主要人物执行亲属词定向复核。检索范围为本地
《三国志》65 卷索引中的本传、同传、附传和裴松之注，重点检查父、母、子、女、妻、
兄弟姊妹、姻亲、收养、嗣承和宗族表述。

本轮正式切换到“人物扩张降级、关系补全优先”：只选择关系双方均已在 577 人冻结名册
中的候选，不新增人物，不因覆盖率目标降低证据标准，也不加入政治、军事、任官或事件
关系。未入名册的具名亲属保留为后续线索，不在本轮为提高数字而扩张名册。

## 结果

- 人物保持 577，不扩张名册；
- 正式关系由 318 增至 324，史料由 156 增至 162；
- 有关系人物由 325 增至 333，孤立人物由 252 降至 244；
- 覆盖率由 56.3% 提高至 57.7%；
- 第二批主要人物孤立队列由 71 降至 64，第六批队列由 180 降至 179；
- 8 名现有人物入网：郭淮、王凌、王允、刘协、张绣、张鲁、陆绩、张温。
