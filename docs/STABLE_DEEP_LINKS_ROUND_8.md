# Round 8：稳定永久链接与长页面滚动

完成日期：2026-08-14

## 完成内容

- 人物永久链接：`#/person/<stable-key>`；
- 关系永久链接：`#/relation/<stable-key>`；
- 史料永久链接：`#/source/<stable-key>`；
- 人物档案、关系档案、史料详情和史料目录互相提供可复制的稳定入口；
- 无效或已损坏的永久链接显示明确的未找到页面，不回退成错误人物或关系；
- 保留 `#/`、`#/sources`、`#/about` 三个既有页面路由；
- 根目录 `index.html` 继续支持直接双击，并跳转至离线单文件应用。

永久链接使用项目本地稳定 ID 的短键，不暴露内部候选标识，也不依赖外部网站。

## 滚动修复

桌面宽屏布局原先把 `html`、`body` 与 `#root` 一并设为固定高度并隐藏溢出，导致
“史料浏览”和“关于项目”只能看到视口内的前半部分。现在固定高度与隐藏溢出只作用于
关系图谱工作台 `.route-home`，文本型页面恢复浏览器原生纵向滚动。

验收要求：

- `#/sources` 与 `#/about` 均可用鼠标滚轮、触控板或滚动条到达页尾；
- 桌面 1366×768 与移动端 390×844 均无横向溢出；
- 离线 `file:` 入口与开发预览行为一致。
