# 第三批家庭扩展

更新时间：2026-08-02

## 范围

第三批优先补齐第二批主要人物的核心家庭，共新增 35 人，使前端正式人物总数
从 200 增至 235。新增人物按展示阵营计为魏 5、蜀 13、吴 15、其他 2；合并后
前端展示计数为魏 75、蜀 58、吴 68、其他 34。

本批只使用既有六类家庭关系：父亲、母亲、配偶、养父、养母、宗族／姻亲。
不增加战争、敌对、主从、官职、联盟、事件或阵营边。

## 人物名单

- 刘备家庭：刘弘、孙夫人、糜夫人；
- 孙氏家庭：孙匡、孙和、孙霸、孙奋、孙鲁班、孙鲁育、徐夫人、琅邪王夫人、南阳王夫人；
- 司马氏家庭：张春华、王元姬、司马炎、司马攸、司马干；
- 蜀汉将领家庭：关平、关兴、张苞、张绍、张遵、马承、马秋、马氏、黄叙、赵统、赵广、黄氏；
- 孙周姻亲：大乔、小乔、周循、周胤、周氏；
- 文学层：貂蝉。

`Person.importBatch` 对上述人物固定为 `3`。姓名未见史籍记载者保持“某氏”、
“某夫人”或亲属称谓，不从后世通俗称呼反推本名。例如诸葛亮之妻录为“黄氏”，
“黄月英”不作为史实名录入。

## 关系与证据层

本批新增 77 条家庭关系，合并后共 110 条：父亲 50、母亲 25、配偶 24、养父 2、
养母 2、宗族／姻亲 7。全部关系均为 `origin: recorded`，并引用非结构化史料。

- 正史或《晋书》直接记载：`confirmed + verified`，前端实线；
- 裴注材料、地方旧闻或制度含义需保守解释：`probable`，前端虚线；
- 《三国演义》中的吕布—貂蝉：`fictional + literature + pending_review`，前端虚线；
- 文学层默认可见但有独立开关，不构成正史承认。

第三批新增 13 条关系级史料，主要定位到《三国志》卷五、三十二、三十四、
三十六、三十八、四十六、五十、五十四、五十八、五十九，《晋书》卷三十一、
《襄阳记》和《三国演义》第十六回。实现文件：

```text
src/data/familyPersons.ts
src/data/familyRelations.ts
src/data/familySources.ts
```

视觉阵营 `Person.visualFaction` 只控制前端配色；它与 `Person.factions` 的历史
归属字段继续分开维护。
