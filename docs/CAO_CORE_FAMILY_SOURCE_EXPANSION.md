# 曹操十五人核心家族多典籍来源扩展

## 范围

本轮只扩展曹操十五人核心家族的正式参考文献，不新增人物或关系，也不改变展示阵营：
曹腾、曹嵩仍为“其他”，其余十三人为“魏”。展示阵营不等于人物生前的正式政治归属。

引用记录保持“书名—卷次—篇名或纪年—原文短摘录”的粒度。史料必须能够定位人物或
直接支持具体关系；只有时代背景而没有人物或关系指向的段落不进入正式来源。

旁证不会替代《三国志》正文，也不会单独把关系提升为 `confirmed`。
