# 关系覆盖第 1 批：魏系主要人物

更新时间：2026-08-09

## 范围与结果

本批审核第二批主要人物队列中的 34 名魏系人物，只检查当前六类家庭关系，并且只在
关系双方均已存在于 537 人正式名册时新增连线。

- 新增 16 条关系和 12 条关系级史料；
- 16 名第二批主要人物由孤立状态接入正式关系；
- 同时接入 8 名第六批人物；
- 正式数据更新为 537 人、200 条关系、121 条史料；
- 有关系人物由 187 人增至 211 人，孤立人物由 350 人降至 326 人。

## 史料与许可边界

关系判断来自《三国志》正文或裴松之注所保存的古代材料。项目沿用既有维基文库链接
作为在线核验入口，只摘录支持关系判断所需的短句，不导入维基文库结构化数据，也不
把外部候选层作为 `confirmed` 依据。
