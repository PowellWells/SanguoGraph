# Round 7 史料浏览与来源详情优化

更新时间：2026-08-13

## 1. 本轮范围

Round 7 进入 Milestone 3 的第一轮，只优化正式史料的浏览与引用语义，不修改冻结的
580 人、358 条关系和 189 条史料，也不提前实现稳定 Deep Link、纠错提交或数据许可
决策。

## 2. 已完成

- 将原来一次性展开的 189 条史料改为可折叠目录；
- 支持按书名、作者、卷篇、引文、人物、别名、关系两端及关系限定语检索；
- 支持按史料层和典籍组合筛选，并提供明确的零结果状态与一键清除；
- 将来源引用拆分为“人物定位引用”“关系支持证据”“关系反对证据”，避免把人物
  条目引用误读为关系证据；
- 在图谱内的当前史料清单增加“打开完整史料浏览器”入口；
- 默认折叠长引文；检索结果较少时自动展开，便于直接核验；
- 保持所有正式史料 URL 为空时不渲染伪造外链，继续执行前端无维基体系文案、链接、
  QID 和候选数据的发布边界。

## 3. 验收口径

- 输入“曹节 刘协”只返回《后汉书》卷十下曹氏三女史料；
- 详情显示 3 个人物定位引用、6 条关系支持证据、0 条关系反对证据；
- 史料层与典籍筛选可独立组合，清除后恢复 189 条；
- 桌面与 390×844 移动端无横向溢出；
- 根目录直接打开入口和离线单文件继续有效；
- 页面无维基体系可见文案或外链。
