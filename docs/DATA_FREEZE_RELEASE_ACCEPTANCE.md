## 1. 冻结前遗漏审计

根据《后汉书》卷十下《献穆曹皇后纪》“操进三女宪、节、华为夫人”及“献穆曹皇后
讳节，魏公曹操之中女也”等正文，本轮补录曹宪、曹节、曹华三名具名人物。三人均由
合格史料立即接入现有关系网，不属于为扩大名册而增加的孤立节点。

原有“汉献帝聘曹操三女”的曹操—刘协聚合占位边已删除，替换为：

- 曹操—曹宪、曹节、曹华三条父女关系；
- 曹宪、曹节、曹华—刘协三条婚姻关系。

六条关系均为 `confirmed + verified + direct_record`，引用同一条带原文摘录、URL
为空的《后汉书》史料。用户提供的网页摘要只用作检索线索，不进入正式数据、前端或
离线成品。

## 4. 发布边界

- 正式网页与离线成品不得显示或链接维基体系名称、域名、QID 或候选结构化数据；
- 内部研究资料可以检索，但不参与正式数据构建或前端打包；
- 正常史料书名、作者、卷次、篇章、引文和参考文献可以展示；
- 根目录 `index.html` 继续直接跳转至 `offline/index.html`，无需本地服务器。
