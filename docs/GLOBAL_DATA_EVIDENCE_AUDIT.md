# Round 5：全局遗漏、身份、来源和证据审计

更新时间：2026-08-12

## 1. 范围与原则

本轮在 577 人冻结名册上执行全局回查，不增加人物，不引入官职、事件、战争、主从或
阵营边，也不因第一阶段覆盖目标而降低证据标准。正式数据继续只收录六类家庭关系；
内部候选材料只用于检索，不参与构建，网页和离线成品不显示或链接维基体系内容。

## 4. 来源与证据审计

- 为 6 条既有家族史料记录补入可核查原文，使此前只引用卷级条目的 33 条正式关系具备
  关系级文本证据。
- 数据校验器新增 `RELATION_WITHOUT_QUOTED_SOURCE`：任何正式关系若未引用至少一条
  非空原文摘录，构建校验直接失败。
- 当前 353 条正式关系全部通过引文校验；其中 322 条为 `confirmed`、30 条为
  `probable`、1 条为文学层 `fictional`，没有把待复核关系伪装成已确认关系。
- 当前共有 188 条史料，185 条被人物或关系实际引用。`sgz_volume_01`、
  `sgz_volume_02`、`sgz_volume_19` 三条卷级身份来源暂未被正式实体引用，但作为
  65 卷来源框架保留，不计入前端可浏览来源数。
