# 第五批蜀系家庭扩展

更新时间：2026-08-02

## 1. 范围

第五批继续“优先扩展已有人物家庭”，在第四批集中补魏之后转向蜀汉区域，新增
35 人，使正式人物从 270 增至 305。新增人物统一使用蜀区展示颜色；
`visualFaction: shu` 只是地图空间与颜色编码，人物的东汉、孙吴、曹魏或西晋经历
仍独立保存在 `factions`。

本批仍不增加政治、战争、主从、官职、联盟、事件或阵营关系。每位新增人物恰好
使用一条必要家庭关系接入，避免把人物扩展演变为高密度关系网。

## 2. 人物名单

- 刘氏与张氏后妃（12）：敬哀皇后、张皇后、刘璿、刘瑶、刘琮、刘瓒、刘谌、
  刘恂、刘璩、刘胤、刘承、刘辑；
- 诸葛氏（6）：诸葛乔、诸葛攀、诸葛显、诸葛瞻、诸葛尚、诸葛京；
- 荆益文臣家庭（7）：庞宏、法邈、许钦、许游、糜威、糜照、马秉；
- 蜀汉将领与宗族家庭（10）：霍弋、向朗、向充、黄邕、黄崇、王训、李遗、
  张瑛、邓良、马修。

同名人物使用独立本地 ID：刘禅之子刘琮为 `person:sg:liu_cong_shu`，不与既有
荆州人物刘琮混同；许靖之孙许游为 `person:sg:xu_you_jing`，也不与许攸混同。

## 3. 关系与史料边界

第五批新增 35 条关系：父亲 32 条、养父 1 条、宗族／姻亲 2 条。合并后正式
关系共 180 条：

- 父亲 115；
- 母亲 25；
- 配偶 24；
- 养父 3；
- 养母 2；
- 宗族／姻亲 11。

诸葛亮收诸葛乔为嗣使用 `adoptive_father_of`，不再额外加入诸葛瑾的生父线；
向朗—向宠、向宠—向充只以两条有界宗族关系表达叔侄和兄弟，不补造中间人物。

刘瑶、刘琮、刘瓒、刘谌、刘恂、刘璩仅见裴松之注引《蜀世谱》，相关关系标记为
`probable + annotated_history + pending_review`，以前端虚线展示。其余本批关系
由《三国志》正文直接支持，标记为 `confirmed + official_history + verified`。
