# 关系覆盖第 3 批：蜀系与其他主要人物

更新时间：2026-08-09

本批完成第二批主要人物队列中最后 47 名人物的审核，包括 20 名蜀系展示人物和
27 名其他展示人物。展示阵营仅用于前端颜色与空间编码，不等同于人物在各时期的
正式政治归属。

在现有 537 人名册和父亲、母亲、夫妻、收养、宗族六类关系范围内，本批新增 8 条
关系及 6 条关系级史料，使 11 名主要人物由孤立状态接入图谱，并同时接入 1 名第六批
人物。新增关系包括马良—马谡、董和—董允、刘备—刘封、马腾—马超、袁绍—袁术、
刘表—刘琮、刘焉—刘璋和公孙度—公孙渊。

前 7 条关系由《三国志》正文直接说明，标记为
`confirmed + direct_record + verified`。公孙度—公孙渊由同段“度死，子康嗣位”和
“康死，子……渊等皆小”的连续父子记载限定推得祖孙关系，标记为
`probable + indirect_inference + pending_review`，没有补造中间人物或把推定关系伪装成
正文直书。

其余 36 名人物在本轮没有新增关系：孙乾、简雍、伊籍、刘巴、孟达、李严、魏延、
杨仪、费诗、蒋琬、费祎、姜维、张翼、宗预、廖化、徐庶、刘协、何进、张角、王允、
董卓、李傕、郭汜、韩遂、沮授、田丰、张邈、陈宫、陈登、臧洪、公孙瓒、刘虞、陶谦、
张燕、张绣、张鲁。“没有新增”只表示当前名册内没有找到可由六类关系安全闭合的
对象，不代表这些人物没有亲属记载。

本批结束后，正式图谱为 537 人、235 条关系、134 条史料；257 人拥有至少一条正式
关系，280 人仍孤立，覆盖率为 47.9%。至此，原定 120 名主要人物的三批审核全部完成。
