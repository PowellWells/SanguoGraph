# 第四批魏系家庭扩展

更新时间：2026-08-02

## 1. 范围

第四批沿用“优先扩展已有人物家庭”的方向，集中补充魏系宗室与主要将领的具名
直系家属，共新增 35 人，使正式人物从 235 增至 270。新增人物全部使用魏区展示
颜色；这只是前端空间与颜色编码，不等同于人物一生中的正式政治归属。

本批不增加战争、敌对、主从、官职、联盟、事件或阵营关系，只使用既有六类家庭
关系。每位新增人物恰好由一条必要关系接入现有图谱，避免扩大成高密度政治网络。

## 2. 人物名单

- 夏侯氏（9）：夏侯充、夏侯楙、夏侯衡、夏侯霸、夏侯称、夏侯威、夏侯荣、
  夏侯惠、夏侯和；
- 曹氏宗室（16）：曹炽、曹泰、曹楷、曹范、曹纯、曹演、曹馥、曹震、曹肇、
  曹羲、曹训、曹则、曹彦、曹皑、曹彬、曹初；
- 五子良将后裔（7）：张虎、张统、乐綝、乐肇、于圭、张雄、徐盖；
- 宿卫与将领后裔（3）：许仪、典满、庞会。

曹洪之子“曹震”使用 `person:sg:cao_zhen_hong`，与既有人物曹真
`person:sg:cao_zhen` 严格区分。`Person.importBatch` 对上述人物固定为 `4`。

## 3. 关系与史料边界

第四批新增 35 条关系：父亲 33 条、宗族／姻亲 2 条。合并后正式关系共 145 条：

- 父亲 83；
- 母亲 25；
- 配偶 24；
- 养父 2；
- 养母 2；
- 宗族／姻亲 9。

关系主要定位到《三国志》卷九、卷十七、卷十八。卷九裴注明确补充的夏侯称、
夏侯荣与曹炽关系标为 `annotated_history`，其余本批关系标为
`official_history`；两者均为直接记名材料，不属于传闻或程序推导。

本批没有加入文学或传闻关系。后续若发现只有后出传闻支持的关系，必须单独标记
可信度和史料层级，并以前端虚线表达，不得混入本批已核验的正史关系。
